A one-line out-of-office auto-reply written as if the office monstera wrote it: its human finally watered it, so now it is too busy photosynthesizing to answer emails — and the human's emails can wait, the way the plant waited. `main.py` writes that single line (115 characters, inside the 120-character gate) to `/output/entry.txt`, refusing loudly if the line ever drifts outside the gate.

## Run it

```sh
python3 main.py
```
